# 中国彩票信息公开平台

## 项目简介
这是一个展示中国各类彩票开奖结果的Web应用，提供双色球、快乐8、福彩3D等多种彩票类型的开奖结果查询、走势图分析和中奖查询功能。项目采用纯前端技术实现，无需后端支持，可直接在浏览器中运行。

## 主要功能

### 双色球功能
- 开奖结果展示：显示历史开奖号码（红球和蓝球）
- 期号查询：支持按期号搜索特定开奖结果
- 走势图：可视化展示号码出现频率和趋势
- 查奖功能：快速查询中奖情况
- 数据统计：计算和值、奇偶比、大小比等统计指标

### 快乐8功能
- 开奖结果展示：按组别分类显示历史开奖号码
- 期号查询：支持按期号搜索特定开奖结果
- 数据统计：计算和值、奇偶比等统计指标

### 福彩3D功能
- 开奖结果展示：显示历史开奖号码（百位、十位、个位）
- 期号查询：支持按期号搜索特定开奖结果
- 走势图：可视化展示号码出现频率和趋势
- 查奖功能：快速查询中奖情况
- 数据统计：计算和值、跨度等统计指标

## 新增功能
- 分页显示：支持自定义每页显示条数
- 本地存储：记住用户选择的每页显示条数
- 响应式设计：适配不同屏幕尺寸
- 数据持久化：使用localStorage保存用户偏好设置

## 使用方法
1. 克隆项目到本地
   ```bash
   git clone https://github.com/yourusername/lottery_data.git
   ```
2. 直接打开index.html文件即可使用
3. 通过导航栏切换不同彩票类型
4. 使用搜索框查询特定期号
5. 点击"查奖"按钮查询中奖情况
6. 点击"走势图"按钮查看号码趋势分析

## 技术栈
- 前端：HTML5, CSS3, JavaScript
  - 使用原生JavaScript实现数据渲染和交互
  - 采用Fetch API异步加载数据
  - 使用localStorage实现本地存储
  - 完全响应式布局，适配移动端
  - 无任何第三方库依赖，轻量高效

## 部署指南
1. 基础部署方式：
   - 将项目文件上传至任意Web服务器
   - 或直接在本地浏览器中打开index.html文件(但可能无法渲染数据)

2. 推荐本地开发环境：
   ```bash
   # 使用Python简单HTTP服务器
   python -m http.server 8000
   
   # 或使用Node.js http-server
   npx http-server
   ```
## 注意事项
- 所有数据均为网络采集，仅供参考，具体开奖信息以福彩、体彩官网为主
- 如需更新开奖数据，请替换data目录下的JSON文件
- 本地直接打开index.html可能无法加载数据，建议使用本地服务器运行
- 项目已实现双色球、快乐8、福彩3D的数据自动更新功能
