# 中国彩票信息公开平台

## 项目简介
这是一个展示中国各类彩票开奖结果的Web应用，提供双色球、快乐8、福彩3D等多种彩票类型的开奖结果查询、走势图分析和中奖查询功能。

## 主要功能

### 双色球功能
- 开奖结果展示：显示历史开奖号码（红球和蓝球）
- 期号查询：支持按期号搜索特定开奖结果
- 走势图：可视化展示号码出现频率和趋势
- 查奖功能：快速查询中奖情况

### 快乐8功能
- 开奖结果展示：按组别分类显示历史开奖号码
- 期号查询：支持按期号搜索特定开奖结果

### 福彩3D功能
- 开奖结果展示：显示历史开奖号码（百位、十位、个位）
- 期号查询：支持按期号搜索特定开奖结果
- 走势图：可视化展示号码出现频率和趋势
- 查奖功能：快速查询中奖情况

## 使用方法
1. 克隆项目到本地
2. 直接打开index.html文件即可使用
3. 通过导航栏切换不同彩票类型
4. 使用搜索框查询特定期号
5. 点击"查奖"按钮查询中奖情况
6. 点击"走势图"按钮查看号码趋势分析

## 技术栈
- 前端：HTML5, CSS3, JavaScript
  - 使用原生JavaScript实现数据渲染和交互

## 部署指南
1. 将项目文件上传至任意Web服务器
2. 或直接在本地浏览器中打开index.html文件(但可能无法渲染数据)

## 注意事项
- 所有数据均为网络采集，仅供参考，具体开奖信息以福彩、体彩官网为主
- 如需更新开奖数据，请替换data目录下的JSON文件
- 本地直接打开index.html可能无法加载数据，建议使用本地服务器运行
- 项目已实现双色球、快乐8、福彩3D的数据自动更新功能
