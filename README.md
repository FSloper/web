# 中国彩票信息公开平台

## 项目简介
这是一个展示中国各类彩票开奖结果的Web应用，提供双色球、快乐8等多种彩票类型的开奖结果查询、走势图分析和中奖查询功能。

## 主要功能

### 双色球功能
- 开奖结果展示：显示历史开奖号码（红球和蓝球）
- 期号查询：支持按期号搜索特定开奖结果
- 走势图：可视化展示号码出现频率和趋势
- 查奖功能：快速查询中奖情况

### 快乐8功能
- 开奖结果展示：按组别分类显示历史开奖号码
- 期号查询：支持按期号搜索特定开奖结果

## 使用方法
1. 克隆项目到本地
2. 直接打开index.html文件即可使用
3. 通过导航栏切换不同彩票类型
4. 使用搜索框查询特定期号
5. 点击"查奖"按钮查询中奖情况
6. 点击"走势图"按钮查看号码趋势分析

## 技术栈

2. 或直接在本地浏览器中打开index.html文件(但可能无法渲染数据)
